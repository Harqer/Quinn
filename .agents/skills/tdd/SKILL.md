# Test-Driven Development (TDD)

This skill enforces a strict TDD workflow.

## Workflow
1. **Red**: Write a failing test for the next piece of functionality you intend to build. Run it and verify it fails.
2. **Green**: Write the minimal amount of code necessary to make the test pass.
3. **Refactor**: Refactor the code for better structure, readability, and performance, while ensuring the test continues to pass.
4. Repeat.
