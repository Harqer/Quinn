Lyria Workflow Plan

Architecture proposal covering multi-device Auth Identities and the full Content Generation pipeline (Music, Podcast, Audiobook, Text Voice, Camera).

1. Auth Identities Schema

To support users signing up to the same account on different devices without automatically merging accounts by email (which poses a security risk), we separate the concept of a User from their AuthIdentity.

Table Field Type Description
AuthIdentities id String (PK) Unique identifier for this specific identity link.
userId String (FK) References the main Users table.
provider String e.g., 'google.com', 'apple.com', 'password'.
providerSubject String The unique subject ID from the auth provider.
Security Rule: Never merge accounts automatically via matching emails in the backend. Users must explicitly link additional providers while authenticated.
