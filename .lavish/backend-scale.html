Latency

Direct-to-Vertex Streaming

By connecting clients directly to the Gemini Live API via Vertex AI for Firebase (bypassing the Node backend entirely for live video/audio streams), we eliminate middleman server hops. This guarantees the absolute lowest latency possible for multimodal chat.

Scale

Serverless Auto-Scaling

The Node.js Genkit orchestration layer is deployed on Cloud Run, which auto-scales horizontally from 0 to thousands of instances based on traffic, ensuring consistent latency during usage spikes without paying for idle capacity.

Compute Isolation

Dedicated GPU Compute for Audio

The Python MRT2 microservice handles heavy, continuous audio generation. Separating this from the Node orchestration allows us to provision expensive GPU instances (via Cloud Run for GPUs or GKE) only where strictly necessary, scaling compute independently from regular app logic.

Data

Edge Caching & Real-time State

Memorystore (Redis) caches intermediate AI contexts, Spotify embeddings, and handles rate-limiting to keep response times sub-millisecond. Cloud Firestore pushes UI updates (like new tracks or playlist changes) globally in real-time.
